# SIH26161 — Dam Break Inundation Modelling

A scenario-based system for dam-break inundation modelling, solver comparison,
satellite flood mapping, and exposure analysis.

## Planned workflow

1. Collect dam, reservoir, terrain, land-cover, and hydrological inputs.
2. Prepare terrain and generate breach scenarios and hydrographs.
3. Run Delft3D FM for regional inundation and SPH for the near-field reach.
4. Produce depth, velocity, arrival-time, exposure, and damage outputs.
5. Compare scenarios and display results in a dashboard.
6. Map observed floods using satellite imagery in Google Earth Engine.

## Status

Project structure created. Models, datasets, results, and validation will be
added as they are implemented.
